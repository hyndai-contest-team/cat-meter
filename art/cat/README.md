# 고양이 일러스트 원본

앱의 고양이 그림은 이 폴더의 SVG가 원본입니다. 고친 뒤 아래 명령으로 Android 벡터 이미지를 다시 만듭니다.

```
python3 tools/svg2vd.py
```

`app/src/main/res/drawable/cat_*.xml`이 새로 생성됩니다. 생성된 XML은 직접 고치지 않습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `loaf.svg` | 기본 자세(식빵). 털 색은 임시 색으로 칠해 둠 |
| `acc_hat.svg` / `acc_sunglasses.svg` / `acc_ribbon.svg` / `acc_scarf.svg` | 소품. 고양이와 같은 좌표계(240×200)에 그려 겹치기만 하면 맞음 |

## 규칙

- 캔버스: `viewBox="0 0 240 200"`. 모든 파일이 같아야 소품 위치가 맞습니다.
- 털 색 자리는 아래 임시 색으로 칠합니다. 앱이 고른 털 색으로 바꿔 칠합니다(`ui/CatCanvas.kt`).

  | 임시 색 | 용도 |
  |---|---|
  | `#FF00FF` | 털 기본 |
  | `#00FF00` | 털 그늘 |
  | `#00FFFF` | 배·주둥이 밝은 부분 |
  | `#FFFF00` | 줄무늬 (치즈·고등어만 보이고 까망·하양은 투명) |

- 그 밖의 색(외곽선 `#3A2E2B`, 볼·코 분홍, 눈, 소품 색)은 그대로 쓰입니다.
- 지원하는 요소: `path`, `ellipse`, `circle`, `rect`(rx 포함), `g`. 그라데이션·필터·마스크·텍스트는 쓰지 않습니다.
- `g`의 transform은 `translate(x y)`와 `rotate(deg cx cy)`만 씁니다.
- Figma에서 내보낼 때는 "Outline text", "Include id attribute"를 켜고, 위 범위를 벗어나는 효과는 쓰지 않습니다.

## 그림체

- 정면 식빵 자세, 굵은 외곽선(3.5), 큰 눈과 흰 하이라이트, ω 입, 볼 터치.
- 특정 캐릭터·일러스트를 따라 그리지 않았습니다. 새 자세도 같은 원칙으로 그립니다.

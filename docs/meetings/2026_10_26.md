**일시:** 2026년 10월 26일 22:21~23:18

**결론:** 최종 아이디어는 확정하지 않음. 각자 AI를 접목한 아이디어를 하나 이상 준비하고, 디스코드에서 공유한 뒤 다음 날 회의에서 확정하기로 함.

| --- | --- | --- |
| 주차 자리 예약 | 쇼핑몰의 지정 주차면을 가까운 거리에서 예약. 제한 시간 내 미도착 시 보증금 미환급 | 기존 주차 서비스와의 차별화, 실제 주차면 확보와 운영 방식 필요 |

| 실시간 노면 위험 지도 | 여러 차량의 와이퍼·전조등·급제동 등 데이터를 모아 도로 위험을 지도에 표시 | 실제 수집 가능한 데이터와 위험 판정의 신뢰도 확인 필요 |

## 집중 논의한 방향 — 노면 위험 지도

차량 센서 데이터와 기상 데이터를 종합해 비·눈·미끄러운 노면 등의 위험을 안내하는 서비스를 검토함. AI를 활용해 주행 경로상 특정 구간에 도착할 시점의 도로 상태를 예측하는 방향까지 논의함.

다만 구현 가능성을 판단하려면 다음 사항을 먼저 확인해야 함.

- Pleos Vehicle SDK에서 실제로 제공하는 데이터와 정확한 API 필드
- ABS·ESC·휠 회전 속도 및 결빙 관련 경고 정보의 접근 가능 여부
- 경고등 상태만으로 실제 노면 위험을 판단할 수 있는지
- 여러 차량의 데이터를 서버에 수집하고 공유하는 방식
- 결빙·블랙아이스 등 위험 상태를 판정하고 검증하는 방법

회의 중 SDK 지원 여부에 대한 상반된 정보가 나왔으며, 지원 여부는 확인되지 않은 상태임. 노면 위험 지도도 최종 선정된 아이디어는 아님.
